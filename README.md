# Tux WebOS
This is a keyboard driven, scrollable tiling window manager inspired webOS.

# Features
- Wofi style launcher to launch applications.

- A in-memory file system in which you can browse folders, read files, and even edit them in the text editor. (Just don't refresh the page, or your edits will be gone forever).

- A fully functional notepad-ish that saves to the virtual file system.

- Tracks the actual windows you have open in the wn and assigns them fake PIDs, plus a fake simulated CPU/RAM load visualizer in system monitor application.

- A iframe based browser. Defaults to ArchWiki because most major sites block iframe embedding for security reasons, but it works perfectly for sites that allow it.

- A neat little command line with a few built-in commands like help, date, echo, and a neofetch (Print fake data btw~).

- Glassmorphism everywhere (just like real hyprland lovers), plus a settings application that lets you swap out the wallpaper (including pasting custom image URLs to chanege it to a wallpaper which u like).

# Keyboard Shortcuts
`Shift + Space` - Opens the launcher.

`Shift + C` - Close the currently active window.

`Shift + I` - Toggle fullscreen for the active window.

`Shift + H / Shift + L` - Cycles focus between your open windows (H for left/ L for right)

`Enter` - Select an app in the launcher to launch.

`Escape` - Unfocus a text box (like in text editor and terminal) or close the launcher.
